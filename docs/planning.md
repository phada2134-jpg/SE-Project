# Week 1 – Project Planning

## Project Title
Markdown Note-Taking Application

## Overview
This project is a JavaFX-based desktop application that allows users
to create, edit, organize, and export notes using Markdown formatting.

## Objectives
- Support Markdown note editing
- Provide live preview
- Save and open notes locally
- Organize notes into folders
- Export notes to HTML or PDF

## Scope
### In Scope
- Desktop application using JavaFX
- Markdown editor and preview
- File management (save/open/export)

### Out of Scope
- Cloud synchronization
- Collaboration features
- Mobile application

| Member 2 | UI Developer | JavaFX UI |
| Member 3 | Backend Developer | Markdown & file handling |
